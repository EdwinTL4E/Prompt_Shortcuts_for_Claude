Prompt Shortcuts for Claude is een interactieve HTML-cheatsheet.
Het is een overzichtspagina met korte commando's die je aan Claude kunt sturen om een antwoord bij te sturen of te verfijnen. Denk aan dingen als:

- eli5 → leg uit alsof je 5 jaar oud bent
- samenvatting → geef de kern in 3 bullets
- factcheck → controleer feiten via web search
- stap voor stap → redeneer expliciet stap voor stap
- pros en cons, tabel, formeel, anders, variatie, enzovoort

De commando's zijn gegroepeerd in categorieën: Uitleg, Kwaliteit, Vorm, Toepassing, Toon, Data & Analyse, Redeneren, Perspectief, Iteratie en Technisch, in totaal zo'n 40+ shortcuts.

De pagina heeft ook een zoekfunctie en een kopieerknop per commando, zodat je snel een shortcut kunt pakken en in je gesprek met Claude kunt plakken.

Kort gezegd: het is een handige referentiekaart om sneller en gerichter met Claude te werken.

Deze HTML-tool is bereikbaar via: https://edwintl4e.github.io/Prompt_Shortcuts_for_Claude/
